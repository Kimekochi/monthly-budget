# Monthly Budget

A simple monthly budget tracker: enter your income, add expenses by category (rent, groceries, subscriptions…), and see what's left. English / Russian interface.

**Open it:** https://kimekochi.github.io/monthly-budget/

- Works in any browser, no download needed
- Can be installed on a phone or computer (Add to Home Screen / Install app)
- Works offline; data stays in your browser on your device
